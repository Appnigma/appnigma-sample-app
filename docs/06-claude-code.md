# 6. Ask from Claude Code

Appnigma has an MCP server, so you can ask for integrations, review plans and
check status from Claude Code, without leaving your editor.

```sh
claude mcp add --transport http appnigma https://engine.appnigma.ai/mcp
```

The first time you use it, Claude Code opens a browser window to sign in.

Then ask in plain words, for example:

- "Ask Appnigma to build a HubSpot integration that syncs our requests as deals."
- "What is the status of our Gong integration?"
- "Show me the plan for the NetSuite invoice sync."
